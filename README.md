# Concert Ticketing

A concert ticketing platform built with Go, PostgreSQL, RabbitMQ, and React. The project focuses on correct seat allocation, reliable payments, asynchronous processing, and operational recovery.

- [Product requirements](docs/PRD.md): users, scope, business rules, journeys, and release acceptance criteria.
- [Technical plan](docs/TECHNICAL_PLAN.md): architecture, stack, persistence, messaging, security, deployment, and implementation milestones.
- [Backend TODO](docs/BACKEND_TODO.md): planned PRs and commits, dependency gates, and backend release validation.
